## 怎麼搬

Claude Code 讀不到 claude.ai 網頁版的對話紀錄，內容要用下面任一種方式送進來：

1. **直接貼** — 把對話內容貼在聊天視窗，分批貼也可以
2. **上傳檔案** — 對話裡的 artifact 或附件下載後，直接上傳到這個 session
3. **Google Drive** — 放進 Drive（本 session 已連 Google Drive，可直接讀取）
4. **官方匯出** — claude.ai 的 Settings → Privacy → Export data，把匯出的 `conversations.json` 送進來
