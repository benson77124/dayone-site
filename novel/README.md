# 小說寫作工作區

從 Claude Chat 的「新小說創作流程啟動」搬過來，之後小說都在這裡寫。

## 資料夾

| 資料夾 | 放什麼 |
| --- | --- |
| `00-匯入/` | 從 Claude Chat 搬過來的原始對話、檔案，未整理前先丟這 |
| `01-設定/` | 世界觀、角色、名詞表等設定 |
| `02-大綱/` | 總綱與分章大綱 |
| `03-章節/` | 正文，一章一個檔案 |
| `04-筆記/` | 進度追蹤、待辦、想法 |

## 檔名規則

正文用 `第NNN章-標題.md`，三位數編號讓檔案自然照順序排：

```
03-章節/第001章-序.md
03-章節/第002章-初遇.md
```

## 寫作流程

1. 設定與大綱先進 `01-設定/`、`02-大綱/`
2. 寫某一章時，先看該章的分章大綱，再寫進 `03-章節/`
3. 寫完一章更新 `04-筆記/進度.md`
4. 設定有變動（角色新增能力、地名改名等）當下就回頭改 `01-設定/`，不要累積

## 版本控制

每一章、每次大改都是一個 commit，訊息寫清楚改了什麼，之後要回頭找版本才方便。
